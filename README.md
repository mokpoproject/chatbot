# chatbot

## 프로젝트 소개

이 프로젝트는 그 지역에 날씨의 영향을 받는 직업 또는 관광목적등으로 사용가능한 날씨 챗봇을 만들것입니다

## 구현할 기능

-[] 날씨,풍속,파도높이등  데이터를 보여주게 출력
-[] 계획중
