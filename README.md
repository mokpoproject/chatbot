# chatbot

## 프로젝트 소개

날씨 앱은 숫자만 보여줘서 어민과 농민이 출항이나 농약 살포 같은 작업을 해도 되는지 직접 판단해야 하고, 풍랑주의보 발효 여부도 전화로 확인해야 하는 불편이 있습니다.
이 프로젝트는 기상청 예보와 기상특보를 바탕으로 "오늘 이 작업을 해도 되는지, 무엇을 조심해야 하는지"를 알려주는 날씨 챗봇을 만듭니다.

## 구현할 기능

- [x] 질문에서 날짜·시각·장소·작업 종류(어업/농업) 알아듣기 (규칙 기반)
- [x] 기상청 단기예보로 기온·강수·풍속·파고 조회
- [x] 어업: 풍속·파고 기준 출항 양호/주의/위험 판단
- [x] 농업: 농약 살포, 작물 건조, 배수로·비닐하우스 점검, 서리·폭염 주의
- [x] 기상특보(풍랑주의보 등)·예비특보 자동 확인
- [x] Streamlit 웹 채팅 화면
- [ ] 물때(조석) 정보
- [ ] 매일 새벽 자동 알림

> 판단 기준은 참고용 규칙이며, 실제 출항 여부는 기상특보와 해경 통제를 따라야 합니다.

## 참고자료 (데이터 출처)

- 기상청, 「기상청_단기예보 조회서비스」, 공공데이터포털 (https://www.data.go.kr/data/15084084/openapi.do)
- 기상청, 「기상청_기상특보 조회서비스」, 공공데이터포털 (https://www.data.go.kr/data/15000415/openapi.do)
- 위 데이터는 공공누리 저작자표시 조건에 따라 출처를 밝히고 이용합니다.

## 실행 방법

1. 공공데이터포털에서 위 두 API를 활용신청하고 인증키를 받습니다.
2. `.env.example`을 복사해 `.env`로 이름을 바꾸고 `KMA_SERVICE_KEY=` 뒤에 인증키를 넣습니다. (`.env`는 `.gitignore`로 업로드되지 않습니다)
3. 패키지를 설치합니다.
   ```
   pip install -r requirements.txt
   ```
4. 실행합니다.
   - 웹 화면: `streamlit run app.py`
   - 터미널: `python chatbot.py`

질문 예시: `오늘 목포 출항해도 돼?`, `성산 풍랑주의보 내렸어?`, `내일 무안 농약 쳐도 돼?`, `특보 전체`
